# КопиМотик — серверная версия

Запускаешь на своём компьютере — люди заходят по сети (или по интернету через
проброс порта/туннель), у каждого свой аккаунт и свои данные. Всё хранится в
одном файле SQLite через тот же `db_adapter.js`.

В этой сборке уже есть доработки: **сортировка целей по важности** + бейджи
приоритета и косметика **«Мотоцикл»** для Мотика 🏍️.

---

## Что нужно

- **Node.js версии 22.5 или новее** — и больше ничего. База работает на
  встроенном модуле `node:sqlite`, никакие пакеты ставить не обязательно.
- Проверить версию: `node -v`. Скачать: https://nodejs.org

## Запуск

Из этой папки:

```bash
node server.js
```

В консоли появятся адреса:

```
КопиМотик · сервер запущен (драйвер: node:sqlite)
  База данных: .../kopimotik.sqlite
  Локально:    http://localhost:3000
  По сети:     http://192.168.1.50:3000   (для других устройств в той же сети)
Остановить: Ctrl+C
```

- **Сам зайди** по `http://localhost:3000`.
- **Другие в твоей сети (Wi-Fi/LAN)** — по адресу `http://<твой-IP>:3000`
  (тот, что в строке «По сети»). Если не открывается у других — обычно мешает
  файрвол: разреши Node принимать входящие подключения на этом порту.

### Настройки (через переменные окружения)

```bash
PORT=8080 node server.js                 # другой порт (по умолчанию 3000)
KM_DB=/path/to/моя_база.sqlite node server.js   # свой файл базы
HOST=127.0.0.1 node server.js            # слушать только localhost (никого из сети)
```

## Где данные и как сделать бэкап

Все данные — в одном файле `kopimotik.sqlite` (рядом с `server.js`, если не задан
`KM_DB`). Чтобы сделать резервную копию — просто **скопируй этот файл**
(желательно при остановленном сервере). Чтобы перенести на другой компьютер —
скопируй файл туда и укажи через `KM_DB`.

Рядом могут появиться `kopimotik.sqlite-wal` и `-shm` — это служебные файлы
режима WAL, удалять их вручную не нужно.

## Как это устроено

```
Браузер (React-приложение)                Твой сервер (server.js)
   window.storage.get/set  ── HTTP ──▶     /api/kv  ──▶  db_adapter.js  ──▶  SQLite
```

- В браузере `window.storage` — тонкая обёртка над REST API (без базы в браузере).
- На сервере ключ `km:user:<имя>` идёт через `db_adapter.js` в реальные таблицы
  (`financial_profiles`, `goals`, `debts`, …); остальное — в таблицу `app_kv`.
- Имя пользователя → `user_id` как `u_<имя>` (например `demo` → `u_demo`).

### Важно про мультиюзер

- **Вход (`km:session`) хранится локально в браузере каждого посетителя** — поэтому
  один вход не перелогинивает остальных.
- **Аккаунты (`km:users`) общие** и лежат на сервере: кто угодно регистрируется
  и логинится с любого устройства. При сохранении список аккаунтов **мержится**,
  чтобы одновременные регистрации не затирали друг друга.
- Кнопка демо-входа использует общий аккаунт `demo` — несколько человек под `demo`
  будут видеть и перезаписывать одни и те же демо-данные. Для реальной работы
  пусть каждый **зарегистрирует свой логин**.

## Безопасность — прочитай перед тем, как открывать наружу

Это приложение для дружеского/демонстрационного использования, не банк:

- Пароли хешируются простым алгоритмом самого приложения (не криптостойким) и
  лежат в общем списке `km:users`. **Не используй здесь важные пароли.**
- Нет HTTPS и нет защиты от подбора. По умолчанию сервер слушает всю сеть
  (`0.0.0.0`).
- **Безопаснее всего** держать сервер в доверенной локальной сети. Если нужен
  доступ из интернета — поставь впереди обратный прокси (nginx/Caddy) с HTTPS и,
  желательно, дополнительную аутентификацию (basic-auth/туннель вроде Cloudflare
  Tunnel или Tailscale). Чтобы вообще никого из сети не пускать — запусти с
  `HOST=127.0.0.1`.

## Необязательно: ускорить базу (better-sqlite3)

`node:sqlite` помечен как «экспериментальный» и печатает предупреждение. Если
хочешь убрать предупреждение и получить чуть больше скорости — поставь
`better-sqlite3`, сервер подхватит его автоматически:

```bash
npm install better-sqlite3
node server.js        # в строке запуска будет "драйвер: better-sqlite3"
```

Это полностью необязательно — без него всё работает.

## Запустить как фоновую службу (по желанию)

- Просто в фоне: `nohup node server.js > kopimotik.log 2>&1 &`
- Под автоперезапуск: `pm2 start server.js --name kopimotik` (если установлен pm2),
  либо systemd-юнит на Linux.

## Состав папки

```
server.js        — сервер (раздаёт приложение + REST API), без обязательных зависимостей
db_adapter.js    — мост состояние<->SQL (тот же, что в браузерной сборке)
schema.sql       — схема БД (ключи (user_id,id) — корректный мультиюзер)
package.json     — метаданные, scripts.start, better-sqlite3 как опциональная зависимость
public/index.html — само приложение (бандл + доработки + fetch-обёртка storage)
```
